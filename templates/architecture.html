Project Architecture

Overview

This book recommendation system uses Flask for the backend and a lightweight frontend. Recommendations are generated using collaborative filtering with K-Nearest Neighbors (KNN).

Architecture Components

  • Data Loading & Preprocessing: Clean book, user, and rating datasets
  • Data Filtering: Reduce dataset size by keeping only active users and popular books
  • Model Training: Train a KNN model on a sparse pivot matrix
  • Serialization: Save model and data using pickle
  • Flask Backend: API for search and recommendations
  • Frontend: Autocomplete & real-time book suggestions

Step-by-Step Workflow

  1. Prepare Datasets: Load and clean data
  2. Filter Users: Keep only users with more than 200 ratings
  3. Filter Books: Keep only books with at least 50 ratings
  4. Train Model: Use collaborative filtering (KNN)
  5. Save Model: Serialize model & pivot table
  6. Deploy: Serve via Flask with interactive frontend
